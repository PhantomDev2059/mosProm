02 · Кейс LinQ

Задача

Сервис, который по видео с камер находит нарушения техники безопасности.
Инференс — обязательно на российском ускорителе LinQ, с замерами скорости.

ОБЯЗАТЕЛЬНО
  • видеопотоки с камер или наборы снимков
  • распознавание нарушений нейросетями
  • оповещение с кадром, камерой и временем
  • одно нарушение — одно оповещение
  • журнал событий с фильтрами
ЖЕЛАТЕЛЬНО
  • зоны и правила под каждую камеру
  • дашборд со статистикой
  • подтверждение и отклонение оператором
  • несколько потоков одновременно

17 · Код

Как кадр уходит на ускоритель

def send_to_tpu(uri, tensors, timeout=30): mid = uuid.uuid4().hex # id задачи ch.basic_publish("tpu.direct", "input", serialize(PyTask(tensors)), BasicProperties(headers={ TARGET_URI: uri, # какая программа .tpu RESPONSE_KEYS: [reply], # куда вернуть ответ MESSAGE_ID: mid})) for _, props, body in ch.consume(reply): if props.headers[MESSAGE_ID] != mid: continue # чужой ответ data, _, worker = deserialize(body) chip_ms = worker["inference_time"] * 1000 return data
  • Чипа рядом нет: кадры идут через очередь RabbitMQ на 16 воркеров
  • У каждой задачи свой id: ответы приходят не по порядку
  • Воркер сообщает время на чипе: отсюда 8–13 мс
  • 12 таких отправителей работают параллельно
